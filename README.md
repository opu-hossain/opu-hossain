### About Me

I am a first-year **B.Sc. Computer Science and Engineering** student based in Bangladesh. I have a strong interest in how things work under the hood, focusing on low-level programming and system architecture, while also exploring modern app development.

*   **Currently focusing on:** C, Kotlin, and Socket Programming
*   **Interests:** Systems Programming, Computer Architecture, Android/KMP, and CLI Tooling
*   **Motto:** *The best way to learn is to do it.*
